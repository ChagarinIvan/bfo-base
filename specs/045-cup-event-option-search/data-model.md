# Data model: Варианты этапов кубка

Новых таблиц, полей и миграций нет.

| Сущность | Используемые поля |
| --- | --- |
| Cup | `id`, `year` |
| Event | `id`, `competition_id`, `name`, `date`, `active` |
| Competition | `id`, `name` |
| CupEvent | `cup_id`, `event_id`, `active` для действующего исключения уже связанных этапов |

Запрос ограничивает годом кубка и отсутствием активной связи с текущим кубком. Текст поиска проверяется по названию Event или Competition. Сортировка по дате убывает, при одинаковой дате `events.id` возрастает. Сервер возвращает страницу из 20 записей и признак следующей страницы.

В состоянии формы `eventId` хранится отдельно от страницы вариантов. Переключение страницы или поиск не сбрасывают выбранный этап.
