# Data model: Варианты этапов кубка

Новых таблиц, полей и миграций нет.

| Сущность | Используемые поля |
| --- | --- |
| Cup | `id`, `year` |
| Event | `id`, `competition_id`, `name`, `date`, `active` |
| Competition | `id`, `name` |
| CupEvent | `cup_id`, `event_id`, `active` для действующего исключения уже связанных этапов |

Запрос ограничивает годом кубка и отсутствием активной связи с текущим кубком. Текст поиска проверяется по названию Event или Competition. Сортировка по дате убывает, при одинаковой дате `events.id` возрастает. Select использует первые 20 записей ответа; признак следующей страницы не отображается.

В состоянии формы `eventId` хранится отдельно от текущего набора вариантов. Изменение поиска не сбрасывает выбранный этап.
