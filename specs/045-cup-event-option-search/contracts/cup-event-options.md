# V1 contract: варианты этапов для кубка

`GET /api/v1/events?year=2026&notRelatedToCup=57&withCompetition=1&sortBy=date&sort=desc&page=1&perPage=20`

Поиск добавляет `competitionOrEventName=bla` после трёх символов. Параметр ищет подстроку без учёта регистра в названии соревнования или этапа. Пустой параметр не передаётся. `sortBy` допускает `date`, `sort` допускает `asc` и `desc`; неверные значения возвращают `422`. По умолчанию существующая сортировка API сохраняется.

Ответ остаётся массивом `ViewEventDto`, с `competitionName` по `withCompetition=1`. Заголовки `X-Pagination-Current-Page`, `X-Pagination-Per-Page`, `X-Pagination-Has-Next` определяют листание без общего количества. Фильтры `year` и `notRelatedToCup` применяются вместе с поиском до разбивки на страницы. При равной дате порядок определяется `events.id` по возрастанию.

`notRelatedToCup` исключает этап при любой активной связи с указанным кубком, даже если у этапа есть связи с другими кубками. Неактивная связь с указанным кубком не исключает этап.

`POST /api/v1/cup-events` и форма редактирования не меняются. Ошибки загрузки вариантов показываются рядом с выбором; форма не подменяет их пустым результатом поиска.
