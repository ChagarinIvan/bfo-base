# Модель данных: `п.п. 20.10`

Постоянная модель не меняется. Parser возвращает существующую строку:

| Поле | Ожидаемое значение |
|---|---|
| `group` | Группа из заголовка блока: Ж12, М21, Open2 и т. д. |
| `lastname`, `firstname`, `club` | Данные участника из исходной строки |
| `year`, `rank`, `runner_number` | Значения до колонки результата |
| `time` | Реальное время или `null` для 20.10 |
| `place` | Место или `null` для 20.10 |
| `complete_rank` | Существующий результат выполнения, обычно `-` |
| `distance` | Длина и количество КП текущей группы |

`пп. 20.10` — входной маркер статуса без результата, а не отдельная доменная
сущность и не время.
