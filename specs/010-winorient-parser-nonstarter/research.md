# Исследование

- Заголовок fixture содержит `WinOrient - Result list`; `ParserFactory` выбирает
  `WinOrientHtmlParser` по `check()`.
- У проблемной строки токены после клуба: `б/р 4 2016 н.старт - -`.
- Парсер читает колонки справа налево. Неизвестное значение времени попадало в ветку
  `else`, где cursor сдвигался ещё раз; год начинал читаться с позиции номера.
- Значения `снят`, `24.4` и `20.10` уже считались отсутствием времени и не делали
  дополнительный сдвиг. `н.старт` добавлено в эту же семантическую группу.
