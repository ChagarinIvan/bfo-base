# Спецификация фичи: корректный импорт WinOrient без старта

**Ветка фичи**: `010-winorient-parser-nonstarter`  
**Создано**: 2026-09-03  
**Статус**: Реализовано

## Входная проблема

Файл `storage/tests/2026/20260725.htm` содержит участницу Андрюшину Екатерину,
которая указана как `н.старт`. У такой строки нет результата и места, но год рождения
`2016` должен импортироваться. Текущий right-to-left разбор WinOrient смещает столбцы
и теряет год.

## Пользовательские сценарии и тестирование

### История 1 — Импорт строки без старта (P1)

При импорте WinOrient-протокола участник без старта сохраняется с корректными
персональными и стартовыми данными, даже если результат отсутствует.

**Независимая проверка**: запустить `WinOrientParserTest` на fixture 20260725.htm.

1. **Дано** строка `Андрюшина Екатерина ... 4 2016 н.старт - -`, **когда** файл
   разбирается, **тогда** год равен `2016`, номер равен `4`, время и место отсутствуют,
   а выполненный разряд равен `-`.
2. **Дано** существующие WinOrient fixtures, **когда** запускается тот же тест,
   **тогда** все прежние ожидаемые результаты сохраняются.

## Граничные случаи

- `снят`, `н.старт` и другие значения без результата не должны сдвигать год и номер.
- Строки с обычным временем, местом и очками должны работать как раньше.
- Неизвестный формат должен по-прежнему отклоняться соответствующим parser check.

## Требования

- **FR-001**: `WinOrientHtmlParser` MUST сохранять 4-значный год перед `н.старт`.
- **FR-002**: `н.старт` MUST трактоваться как отсутствие времени без дополнительного
  пропуска колонки.
- **FR-003**: Regression-тест MUST использовать реальный fixture `20260725.htm` и
  сохранять все существующие тесты парсера.
- **FR-004**: Изменение MUST быть минимальным и не менять правила обычных строк.
- **FR-005**: В репозитории MUST появиться skill с TDD-процессом доработки парсеров.

## Критерии успеха

- **SC-001**: `WinOrientParserTest` проходит для нового и всех старых fixtures.
- **SC-002**: Для строки Андрюшиной импортируются год `2016` и номер `4`, без времени
  и места.
- **SC-003**: Skill описывает обнаружение parser-а, red test, минимальный fix и
  обязательный regression-прогон.

## Допущения

- Формат и кодировка fixture остаются ответственностью существующего WinOrient parser.
- Миграции и изменение публичного API не требуются.
