# Implementation Plan: Переработка тестового набора (скорость, чистота, покрытие)

**Branch**: `003-test-suite-overhaul` | **Date**: 2026-08-27 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/003-test-suite-overhaul/spec.md`

## Summary

Работа над **тестами и их инфраструктурой** без изменения поведения приложения, три направления.
**US1 (P1)**: ускорить прогон — главный рычаг параллельный запуск (`--parallel` с отдельной тест-БД на
процесс) + гигиена фикстур; транзакционный откат уже обеспечен `RefreshDatabase`; MySQL как тест-СУБД
сохраняем (SQLite отвергнут из-за MySQL-специфичного SQL). Цель US1 — **заметно быстрее базовой линии**
(сравнение замеров до/после, без жёсткого числового порога — уточнение 2026-08-27). **US2 (P2)**: ноль
deprecations/notices — аудит `--display-*` и починка первопричин без подавления. **US3 (P3)**: **широкий**
охват целевой DDD-архитектуры (систематически доменные/Application-сервисы, сложные выборки репозиториев,
интеграционные API/контроллеры), особая осторожная характеризация ranks/cups. Каждый шаг — зелёные гейты
и отдельный коммит.

## Technical Context

**Language/Version**: PHP 8.5; Laravel 13.26.1; PHPUnit 13.3.

**Primary Dependencies**: PHPUnit, Laravel testing (`RefreshDatabase`, фабрики), paratest (через
`php artisan test --parallel`), Mockery/PHPUnit-моки. Инструменты качества: PHPStan/Larastan lvl 5,
php-cs-fixer, Rector.

**Storage**: MySQL — тест-СУБД (`.env.testing`, база `bfo_base`, 65 миграций). Сохраняется; SQLite не
используем (MySQL-специфичный SQL: `CONCAT`, multi-table DELETE+JOIN).

**Testing**: 112 файлов / ~237 тестов; 50 на `RefreshDatabase` (транзакционный откат + разовый
`migrate:fresh`). Гейты: `composer test`/`stan`/`cs`/`rector`, все на PHP 8.5.

**Target Platform**: локально — PHP 8.5 на маке + MySQL; CI — GitHub Actions (mysql:8.4, PHP 8.5).

**Project Type**: Web-приложение (Laravel-монолит, слои DDD + Bridge).

**Performance Goals**: полное время прогона **заметно меньше** базовой линии — оценка прямым сравнением
замеров «до/после» (SC-001, **без жёсткого числового порога** — уточнение 2026-08-27); цель — кратное
ускорение через параллелизм, где достижимо, но приёмка не завязана на конкретную цифру.

**Constraints**: поведение приложения неизменно (FR-012); изоляция тестов сохраняется (FR-003); ноль
предупреждений без подавления (FR-006); новое покрытие — только целевая архитектура, легаси не трогаем
(FR-007…FR-009); каждый шаг — зелёные гейты + отдельный откатываемый коммит (FR-013).

**Scale/Scope**: US1 — инфраструктура (`phpunit.xml`/`TestCase`/`.env.testing`/фабрики). US2 — точечные
правки тестов/вызовов. US3 — **широкий охват целевого слоя** (уточнение 2026-08-27): систематически ~42
`Application\...Service`, доменные сервисы `Domain/Rank/*`, `Domain/Cup/*` и др., сложные выборки
Eloquent-репозиториев целевого слоя, интеграционные API/контроллеры; ranks/cups — приоритетно и осторожно.

### Source Code (repository root)

```text
phpunit.xml               # US1: параллелизм/настройки; US2: --display-* режим прогона
.env.testing              # US1: тест-БД (per-process при --parallel)
tests/TestCase.php        # US1: общая тест-инфра (при необходимости)
tests/CreatesApplication.php
database/factories/       # US1: гигиена фикстур (make vs create, меньше строк)
tests/Domain/**           # US3: юнит-тесты доменных сервисов (Rank/Cup и др.)
tests/Application/**       # US3: тесты Application-сервисов (моки интерфейсов)
tests/Infrastructure/**   # US3: тесты сложных выборок целевых Eloquent-репозиториев (НОВЫЙ каталог)
tests/Bridge/Laravel/Http/** # US3: интеграционные request/API-тесты контроллеров
tests/**                  # US2: точечные правки под ноль предупреждений

app/**                    # US2: правки вызовов ТОЛЬКО для устранения deprecation (без смены поведения)
```

**Structure Decision**: новых каталогов в `app/` не создаём. Единственный новый тест-каталог —
`tests/Infrastructure/**` (под тесты выборок целевых репозиториев, T015); остальные тесты идут в
существующую раскладку `tests/{Domain,Application,Bridge}`. US1 — инфраструктура прогона. US2 — точечные
правки тестов (и минимально app при deprecation-вызовах). Легаси (`app/Repositories`, `app/Services`)
новыми тестами не трогаем.
