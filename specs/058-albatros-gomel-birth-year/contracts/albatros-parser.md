# Контракт разбора результата 20.10

Публичный вход: `ParserFactory::createProtocolParser(..., 'htm')` и `parse()`.

При `пп.20.10` или ранее поддерживаемом `пп. 20.10` поле `time` равно `null`. Значения слева от результата читаются из исходных колонок. Для `-` в месте возвращается `place = null`, для `в/к` также возвращается `vk = true`. Дефис в «Вып» остаётся строкой `'-'`, дефис в очках даёт `points = null`. При наличии двух колонок справа от результата парсер читает их по заголовку группы.
