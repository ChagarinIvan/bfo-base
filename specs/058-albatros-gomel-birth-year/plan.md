# План исправления импорта Albatros-Timing

[Спецификация](spec.md)

## Контекст

PHP 8.5, Laravel 13, HTML Windows-1251. Исправление в существующем `AlbatrosTimingParser`. Контрольный файл хранится рядом с другими протоколами в `storage/tests/2026`.

## Проверка конституции

- Меняется только разбор входного файла в существующем адаптере. Путь через `ParserFactory` и передача года в `ProtocolLineInput` уже работают.
- Разбор не обращается к БД. Границы агрегатов, транзакции, аудит, события и политика удаления к исправлению парсера не применяются.
- Регрессионный тест использует исходный файл и запускается до правки. Остальные тесты сохраняют свои ожидания.
- Для выпуска требуется запись в истории обновлений. Проверки включают parser suite, Composer test/CS/STAN/Rector, frontend CI и запуск приложения.

## Решение

Нормализовать написания правила 20.10 в один токен результата. Сохранить место, выполненный разряд и очки по объявленным в заголовке колонкам. Для Word-протоколов сохранить обработку лишних дефисов. При разборе результата 20.10 вернуть пустое время и перейти к номеру участника.
