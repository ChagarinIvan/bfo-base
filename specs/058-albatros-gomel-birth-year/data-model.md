# Данные строки протокола

| Поля | Источник |
|---|---|
| `serial_number`, `lastname`, `firstname`, `club` | Начало строки |
| `year`, `rank`, `runner_number` | «Г.р.», «Квал», «Номер» |
| `time`, `place`, `complete_rank`, `points` | «Результат», «Место», «Вып», «Очки» |
| `vk` | Маркер `в/к` в месте |
| `group`, `distance` | Заголовок группы и параметры дистанции |

Стандартный адаптер импорта передаёт год рождения из строки в `ProtocolLineInput` и в генератор строки идентификации спортсмена.
