# Проверка

1. Запустите `php vendor/bin/phpunit tests/Models/Parser/AlbatrosTimingParserTest.php --filter gomelSprint`. Через фабрику должен разобраться исходный гомельский протокол. Тест сверяет количество строк и контрольные результаты.
2. Запустите `php vendor/bin/phpunit tests/Models/Parser`. В наборе есть июльский протокол с `пп. 20.10` и другие форматы.
3. При сравнении всего гомельского файла проверьте 214 троек «Г.р.», «Квал», «Номер» по порядку строк. Пробелы в фиксированных колонках используются для выравнивания.
