# Проверка фичи: Единая нормализация названий клубов

## Предусловия

1. Локальное окружение Laravel и MySQL подняты.
2. Зависимости Composer установлены.

## Целевые сценарии

1. Запустить узкие тесты domain-правил клуба и убедиться, что варианты с регистром,
   кавычками, аналогами символов, известными вариантами и внешними пробелами дают
   одинаковое сопоставимое имя.
2. Проверить создание и обновление клуба: эквивалентный существующему name
   отклоняется как дубликат, уникальный сохраняется.
3. Разобрать fixture протокола, где club имеет внешние пробелы; результат parser
   pipeline должен содержать очищенное значение.
4. Открыть legacy-протокол с ранее сохранённой строкой club с внешними пробелами;
   строка получает ссылку на правильный активный клуб.
5. Запустить импорт, консольную идентификацию и legacy-извлечение персоны на
   варианте названия клуба; при совпадении заполняется тот же club_id.
6. Убедиться поиском по кодовой базе, что ClubFinder и
   NormalizedNameClubFinder отсутствуют, а правила нормализации определены один раз.

## Команды проверки

~~~sh
vendor/bin/phpunit tests/Domain/Club tests/Services
composer cs
composer stan
composer rector -- --dry-run
composer test
~~~

## Ожидаемый результат

- Все проверки зелёные.
- Удалённые Finder-классы и DI-binding не имеют usages.
- Внешние HTTP-контракты не изменились.
- Новых N+1 или дополнительных запросов в legacy-рендере не появилось.
