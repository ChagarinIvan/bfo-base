# Журнал проверки 057

## Репозиторий

- До обновления `composer audit --locked --no-dev --no-interaction` подтвердил CVE-2026-128083. После обновления Laravel 13.39.0 → 13.43.0 результат 0 advisories. Другие версии из Composer lock-файла остались прежними.
- `composer install` по lock-файлу и package discovery завершились. Сетевой фильтр Composer в песочнице был недоступен. Отдельный аудит с разрешённым доступом ответил успешно.
- `composer validate --strict`, `composer check-platform-reqs` и запуск `php artisan --version` прошли на локальном PHP 8.5.10. Они не подтверждают выполнение тестов на целевом PHP 8.5.13.
- `npm audit --omit=dev` нашёл один High advisory в `source-map-js` 1.2.1. После обновления до 1.2.4 и на итоговом lock-файле production audit вернул 0.
- Полный npm audit до обновления тестового стека показал 2 Critical, 5 High и 15 Moderate. После совместимых обновлений, Vitest 5.1.1 и Happy DOM 21.0.4 остались 14 Moderate только в dev-зависимостях. High и Critical нет. Проверено без подавления advisories.
- Полный Composer audit не нашёл advisories. Его код выхода 1 вызван существующим предупреждением об abandoned dev-пакете `symplify/rule-doc-generator-contracts`.
- `composer test` на локальном PHP 8.5.10 и изолированной MySQL БД `bfo_base_test` прошёл 748 тестов и 5680 assertions. PHPUnit сообщил 15 notices. PHP CS Fixer и PHPStan прошли. Полный Rector dry-run прошёл после обновления Laravel, изменения импорта и Horizon затем проверены отдельным dry-run.
- Итоговый `npm ci` и `npm run ci` прошли на Node.js 22.23.5 и npm 10.9.11 с Vitest 5.1.1 и Happy DOM 21.0.4. Линт, проверка типов, 86 файлов, 304 теста и сборка SPA прошли. В тесте 50 строк колонки теперь включаются до монтирования. Проверки числа строк и запросов сохранены. Vite вывел предупреждение о размере чанка.
- В Dockerfile и CI зафиксирован PHP 8.5.13. Локальный OrbStack остановлен, Docker-образ здесь не собирался. Для проверки нового web-runtime нужен запуск образа в CI или отдельной среде.
- [Аудит репозитория и окружения](audit.md).
