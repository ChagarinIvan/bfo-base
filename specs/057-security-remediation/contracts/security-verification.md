## Импорт протоколов по ссылке

`POST /api/v1/competitions/{competitionId}/events` и `PUT /api/v1/events/{eventId}`
используют тот же параметр `url`. Сервер скачивает HTML с `obelarus.net` по HTTPS с
проверкой сертификата и без перенаправлений. Ссылки HTTP того же домена открываются по
HTTPS. Остальные домены, ошибки загрузки и ответы свыше 10 МиБ возвращают действующую
ошибку `400 invalid_protocol`. Источник `protocol` может по-прежнему быть файлом.
