# Записи проверки

Фича не вводит таблиц. Записи хранятся в отчёте аудита и журнале проверки.

| Запись | Поля |
| --- | --- |
| Окружение | Среда, роль компонента, источник пакета или образа, установленная и запущенная версии, дата и способ проверки |
| Уязвимость | CVE или advisory, компонент и среда, применимость, исправленная версия поставщика, ссылка на доказательство и повторная проверка |
| Находка аудита | Идентификатор, приоритет, область, доказательство, ответственный, действие и статус |
| Выкат | Окно, проверка восстановления, шаг переключения, сценарии smoke, решение и подтверждение отката при необходимости |

Применимость статуса. `unknown` до инвентаризации, `affected` при совпадении с диапазоном поставщика, `verified fixed` после обновления и подтверждения работающей версии, `not applicable` с доказательством. Закрытие находки требует повторной проверки. Фактические версии среды записываются отдельно от деклараций репозитория. Секреты и персональные данные в отчёт не копируются.
