# Контракт групп кубка

| Исходный className | Сохранённое имя | Зачёт |
| --- | --- | --- |
| Nigth Trail Elite - Mужчыны | Nigth Trail Elite - М | M_0_Elite–M |
| Nigth Trail Elite - Жанчыны | Nigth Trail Elite - Ж | W_0_Elite–W |

Действующие API таблицы и очков этапа, пагинация, ID групп и формула очков сохраняются. Мужская группа не попадает в женский зачёт и наоборот. Остальные категории и прежние aliases сохраняют прежнее поведение.

Уже закэшированную пустую таблицу необходимо сбросить штатной очисткой таблиц кубков. После очистки повторное чтение учитывает сохранённые результаты без изменения протокола.

Для всех существующих шаблонов «Лосиной сцежки» обычные пробелы игнорируются с обеих сторон сравнения. Например, `%Elite-М` выбирает `Nigth Trail Elite - М`, `Night Trail Elite - М` и `Autumn Cup Elite  -  М`. `%Elite-Ж` выбирает соответствующие женские группы. `Elite Open - М` не совпадает. Остальные типы кубков и обычный groupNames сохраняют прежнее поведение; названия в БД не изменяются. Пустой список шаблонов не выбирает никакую дистанцию.
