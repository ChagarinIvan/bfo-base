# Модель данных

## Существующие сущности

- `Group`: `name` сохраняет `Nigth Trail Elite - М` или `Nigth Trail Elite - Ж`; `normalize_name` используется импортом для повторного использования группы.
- `Distance`: связывает группу и этап; критерий `groupNamesIgnoringSpaces` выбирает по отображаемому `name`, удаляя обычные пробелы в имени и шаблоне только для сравнения. Обычный `groupNames` не меняется.
- `ProtocolLine`: результат и связь со спортсменом; отбор ограничен выбранной дистанцией и действующими фильтрами.
- `CupGroup`: стабильные ID `M_0_Elite–M` и `W_0_Elite–W` сохраняются.
- Таблица кубка: вычисляемое значение под cache tag cups; после очистки строится из прежних данных с расширенным сопоставлением.

## Инварианты

Мужская и женская группы различны. Прежние aliases сохраняются без добавления названий конкретных этапов. Протокол, схема, исходные группы и результаты не изменяются. Миграций, новых состояний и событий нет.
