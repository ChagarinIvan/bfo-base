# План восстановления подсчёта стартов для IIIю

## Подход

В `EloquentRankFactsCollector` преобразовывать зачётный результат в `RankFact`. Если `RankNormalizer` не возвращает разряд, использовать `Rank::WithoutRank`. Финиш без выполнения учитывается при наличии исходного протокола события. У объединённых этапов поле `file` пустое по контракту спецификации 025. Тест `UniteEventsTest` проверяет их исключение. Фильтры активности соревнований и событий, привязки к спортсмену, времени, массовых стартов и выступлений вне конкурса сохраняются.

`RankCalculator` уже считает такие факты при вычислении IIIю и исключает их из истории существующих выполнений. Он же применяет возраст, календарный год, дату третьего старта и приоритет разрядов. Запрос сохраняет существующую предварительную загрузку событий и соревнований.

Добавить регрессионный тест в `RebuildPersonRanksActionTest` и запись в статический каталог обновлений на белорусском языке.

## Проверка конституции

PHP 8.5, Laravel 13, MySQL. Коррекция касается чтения в существующем репозитории фактов. `RebuildPersonRanksService` и `StandardEventPersonRankUpdater` используют один сборщик. Перерасчёт сохраняет блокировку спортсмена, аудит, публикацию события и атомарное сохранение истории и действующего разряда. Политика доставки событий и удаления источников, схема БД и контракт API сохраняются. Дополнительных SQL-запросов нет.

Сначала воспроизвести дефект через API. Затем выполнить узкие проверки разрядов и полный прогон PHP, SPA и инструментов анализа. Запустить Laravel локально.
