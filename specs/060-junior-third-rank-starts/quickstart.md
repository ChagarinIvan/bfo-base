# Проверка

1. Создать юниора с двумя зачётными финишами без выполненного разряда в одном календарном году. Добавить финиш в другом году и выступления, которые не идут в зачёт.
2. Пересчитать разряды. История пуста.
3. Добавить третий зачётный финиш без указанного выполнения. Пересчитать дважды. В истории одна запись IIIю со ссылкой на третий результат и датой активации в день старта.
4. Проверить существующие сценарии явного и ручного выполнения, историю и замену протокола.
5. Выполнить `composer test` на тестовой БД, `composer cs`, `composer stan`, `composer rector -- --dry-run`, `npm run ci` на Node.js 22 и `git diff --check`. Проверить локальный запуск Laravel. На `/app/updates` есть запись о восстановлении подсчёта.
