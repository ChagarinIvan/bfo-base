# Контракты активации

## Создание ручной даты

`POST /api/v1/person-rank-history/{protocolLineId}/activation` с телом `{"date":"YYYY-MM-DD"}`. Существующие авторизация и успешный ответ `ViewProtocolLineDto` сохраняются. Дата равна дате выполнения или позже. Более ранняя дата возвращает HTTP 422 и код `rank_activation_before_achievement`; запись и событие не создаются.

## Изменение или отмена

`PUT /api/v1/person-rank-history/{protocolLineId}/activation` с такой же датой или `null`. Ненулевая дата проверяется по тому же правилу. `null` убирает ручную дату; для нового целевого выполнения снова действует месячный срок. Для старого или подтверждаемого вручную разряда сохраняется прежнее правило.

## История и текущий разряд

Существующие read API и DTO не получают новых полей. До срока выполнение отображается с `activatedOn: null`; после срока — с датой месячной активации. Ежедневное задание расширяет область пересчёта на ожидающих спортсменов без нового публичного маршрута.
