# Research: Экспорт таблицы кубка

## Исторический HTML

**Decision**: Восстановить HTML как новый документ из общего export DTO.

**Rationale**: Удалённый в 037 Blade-шаблон строил таблицу одной группы на Eloquent-данных и самостоятельно считал суммы. Текущий CSV строится из `CupTableBuilder` для всех групп, а `CupExportAssembler` уже переносит этапы, строки и итоги в `ExportCupTableDto`. Возврат старого шаблона раздвоил бы расчёт.

**Alternative considered**: Вернуть Blade и старый route. Он противоречит завершённому отказу от legacy Web и не даёт одного источника очков.

## Формат запроса

**Decision**: `GET /api/v1/cups/{cupId}/export?format=csv|html`; отсутствие параметра означает CSV. Валидация допускает только эти два значения.

**Rationale**: Один route и один Application service. Старый URL остаётся рабочим, новый клиент указывает формат явно.

HTTP-ответ для обоих форматов собирает один Bridge-assembler: он выбирает сериализатор, MIME и расширение и единожды выставляет attachment header. Action только вызывает сервис и assembler.

CSV-сериализатор добавляет UTF-8 BOM перед первой строкой. Excel в Windows ориентируется на эти байты при открытии скачанного `.csv`; HTTP `charset` сам по себе не сохраняется в файле. Разделитель `;` и CRLF остаются прежними.

## Документ и безопасность

**Decision**: HTML-файл содержит UTF-8 doctype, заголовок кубка и таблицу для каждой группы. Таблицы повторяют CSV-колонки. Все пользовательские строки экранируются, оформление встроено в файл. Ответ содержит `text/html; charset=UTF-8` и attachment filename.

**Rationale**: Самостоятельный файл можно открыть вне сайта; имена и названия не могут стать HTML-кодом.

## Выбор в интерфейсе

**Decision**: Кнопка «Экспарт» открывает PrimeVue `Menu` с двумя командами. Скачивание идёт существующим авторизованным Axios-клиентом; имя локального файла соответствует выбранному формату.

**Rationale**: Браузерная ссылка на API потеряла бы Bearer-токен. Кнопка и меню доступны с клавиатуры.
