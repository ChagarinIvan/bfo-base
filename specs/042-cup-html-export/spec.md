# Feature Specification: Экспорт таблицы кубка в CSV и HTML

**Feature Branch**: `master`  
**Created**: 2026-10-07  
**Status**: Implemented  
**Input**: Первый пункт `plan.txt`: вернуть HTML-экспорт кубка; кнопка экспорта открывает выбор CSV или HTML. Формат передаётся параметром `format`, оба файла строятся из одних данных.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Выбрать формат полного экспорта (Priority: P1)

Авторизованный пользователь открывает кубок, нажимает «Экспарт» и выбирает CSV или HTML. Скачивается один файл выбранного формата с полными таблицами всех групп кубка.

**Why this priority**: HTML-файл ранее был доступен и нужен наряду с действующим CSV.

**Independent Test**: Открыть кубок с несколькими группами, скачать оба формата и сверить состав групп, участников, этапов и итоговых очков с таблицей на сайте.

**Acceptance Scenarios**:

1. **Given** авторизованный пользователь на странице кубка, **When** он открывает меню «Экспарт», **Then** видит два пункта «CSV» и «HTML» без немедленного скачивания.
2. **Given** кубок с результатами в нескольких группах, **When** пользователь выбирает HTML, **Then** получает читаемый HTML-файл со всеми группами, этапами, местами и итогами.
3. **Given** тот же кубок, **When** пользователь выбирает CSV, **Then** получает CSV с теми же результатами.
4. **Given** страница отдельной группы, **When** пользователь выбирает CSV или HTML, **Then** получает только эту группу; на странице этапов экспорт включает все группы.
5. **Given** запрос экспорта выполняется, **When** пользователь смотрит на кнопку, **Then** она недоступна и показывает индикатор загрузки до завершения или ошибки.

---

### User Story 2 - Стабильный контракт скачивания (Priority: P2)

Существующий клиент может скачать CSV по прежнему адресу. Новый клиент выбирает формат явно. Ошибки не выдают файл.

**Why this priority**: Восстановление HTML не должно ломать действующий экспорт CSV.

**Independent Test**: Проверить запросы без параметра, с `format=csv`, `format=html`, неверным форматом, неизвестным кубком и без входа.

**Acceptance Scenarios**:

1. **Given** действующий кубок, **When** запрос не содержит `format` или содержит `format=csv`, **Then** скачивается одинаковый CSV.
2. **Given** действующий кубок, **When** запрос содержит `format=html`, **Then** скачивается HTML с корректным типом и расширением файла.
3. **Given** неверный формат, неизвестный кубок или гость, **When** он запрашивает экспорт, **Then** получает существующий формат ошибки, без скачивания файла.

### Edge Cases

- Кубок без этапов или результатов даёт файл с заголовками групп без вымышленных строк.
- Несколько групп и этапов сохраняют тот же порядок, что текущий экспорт.
- HTML выделяет жирным очки этапов, которые пошли в зачёт; остальные очки остаются обычными.
- В ночном режиме фон и текст очков таблицы сохраняют читаемую контрастность.
- Имена с `<`, `&`, кавычками и переводами строки отображаются как текст, а не как разметка.
- Длинное имя кубка не должно ломать имя скачиваемого файла.
- Меню доступно с клавиатуры и не видно гостю.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Существующее действие «Экспарт» MUST открывать выпадающий список из двух форматов: CSV и HTML.
- **FR-002**: Выбор пункта MUST скачивать один полный файл соответствующего формата и сохранять пользователя на странице кубка.
- **FR-003**: Оба файла MUST использовать один и тот же рассчитанный набор групп, этапов, участников, мест и очков; фильтры и пагинация экранной таблицы не обрезают экспорт.
- **FR-004**: Запрос с `format=csv` и запрос без `format` MUST возвращать одинаковый CSV с прежними разделителем, экранированием и порядком строк. CSV MUST начинаться с UTF-8 BOM для корректного открытия кириллицы в Excel на Windows.
- **FR-005**: Запрос с `format=html` MUST возвращать самостоятельный читаемый HTML-файл в UTF-8 с расширением `.html`; пользовательские значения MUST выводиться безопасно как текст.
- **FR-006**: Неверный формат MUST возвращать ошибку валидации без файла. Гость и неизвестный кубок MUST сохранять действующие ответы доступа и отсутствия ресурса.
- **FR-007**: Выбор формата MUST быть доступен с клавиатуры; ошибка скачивания MUST быть видна пользователю.
- **FR-008**: На странице группы SPA MUST передавать `groupId` в DTO запроса экспорта. Сервис MUST строить только эту группу после проверки, что кубок её поддерживает. Без `groupId` сохраняется полный экспорт.
- **FR-009**: HTML MUST выделять жирным зачётные ячейки этапов по `counted` в общей таблице.
- **FR-010**: В ночном режиме зачётные и незачётные очки MUST иметь тёмные подложки и читаемый текст.
- **FR-011**: Пока запрос экспорта выполняется, кнопка MUST быть недоступна и показывать индикатор загрузки вместо значка экспорта. После завершения и ошибки кнопка снова доступна.
- **FR-012**: Экспорт разрядов и расчёт разрядов остаются отдельными задачами.

### Key Entities

- **Полная таблица кубка**: имя кубка и упорядоченные секции групп; каждая секция содержит этапы, места участников и итоговые очки.
- **Формат экспорта**: CSV или HTML, выбираемый для одного и того же набора данных.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Пользователь скачивает CSV или HTML не более чем за два действия со страницы кубка.
- **SC-002**: Для контрольного кубка 100% групп, участников, этапов и итоговых очков совпадают в обоих файлах и с полной таблицей сайта.
- **SC-003**: Старый запрос без параметра и запрос с `format=csv` дают одинаковое содержимое файла.
- **SC-004**: Некорректный формат, неизвестный кубок и гостевой запрос не создают файл в 100% проверенных сценариев.
- **SC-005**: На странице группы оба файла содержат одну выбранную группу; на странице этапов сохраняется полный экспорт.
- **SC-006**: Зачётные очки HTML выделены жирным, а кнопка экспорта недоступна на протяжении запроса.

## Assumptions

- HTML, как и CSV, скачивается как файл, а не открывается новой страницей.
- HTML отражает текущие доступные поля полной таблицы. Удалённый ранее Blade-шаблон с иным расчётом очков не возвращается.
- Оба формата доступны тем же авторизованным пользователям, которым сейчас доступен CSV.
