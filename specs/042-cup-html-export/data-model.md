# Data Model: Экспорт кубка

Новых хранимых сущностей нет. `ExportCupTableDto` остаётся общей проекцией для CSV и HTML.

| Поле | Содержание |
| --- | --- |
| `cupId`, `cupName` | Идентичность и имя файла/заголовка |
| `sections[]` | Упорядоченные группы кубка или одна выбранная группа |
| `sections[].stages[]` | Идентификатор этапа и дата |
| `sections[].rows[]` | Место, имя, год, клуб, итог и очки по этапам |

Инварианты: оба сериализатора получают один и тот же DTO; `groupId` в запросе ограничивает построение одной поддерживаемой группой, но экранные фильтры и пагинация не применяются; отсутствующая ячейка этапа остаётся пустой; HTML экранирует текстовые поля и выделяет зачётные ячейки по `counted`.
