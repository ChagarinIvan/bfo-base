# Контракт полного экспорта кубка

`GET /api/v1/cups/{cupId}/export` требует действующий Bearer token.

| Query | Успешный ответ | Файл |
| --- | --- | --- |
| отсутствует | `text/csv; charset=UTF-8` | `.csv` |
| `format=csv` | `text/csv; charset=UTF-8` | `.csv` |
| `format=html` | `text/html; charset=UTF-8` | `.html` |

Необязательный `groupId` содержит ID группы, например `W_45_`. С ним CSV и HTML содержат только одну секцию; без него все группы кубка. Если `groupId` передан, он обязателен как непустая строка и должен соответствовать шаблону ID группы. Неверное значение возвращает `422` с полем `groupId`, группа вне кубка возвращает `400` с кодом `cup_group_not_supported`.

Успешный ответ имеет `Content-Disposition: attachment`. CSV начинается с UTF-8 BOM (`EF BB BF`), чтобы Excel в Windows распознал кириллицу. Запросы без параметра и с `format=csv` побайтово совпадают. Разделитель `;`, окончания строк CRLF, экранирование и порядок строк сохраняются. HTML содержит самостоятельный документ UTF-8, заголовок кубка, по одной таблице на группу и те же данные строк, что CSV: место, имя, год, клуб, очки, даты этапов и очки по этапам. Текстовые значения экранируются, зачётные ячейки этапов выделяются жирным.

`format` с другим значением возвращает `422` JSON с полем `format`; неизвестный кубок возвращает `404` JSON с `cup_not_found`; гость получает `401`. Эти ответы не содержат attachment. Старый групповой export route остаётся удалённым.

В SPA пункт CSV вызывает этот route с `format=csv`, пункт HTML с `format=html`. Страница группы также передаёт `groupId`; страница этапов его не передаёт. Оба используют авторизованный клиент, скачивают файл и не меняют страницу. Меню видно только авторизованному пользователю. На время запроса кнопка экспорта заблокирована и показывает индикатор загрузки.
