# Контракт удаления: FAQ-раздел

## Поведение публичных маршрутов

| Запрос | Требуемый результат |
|---|---|
| GET /faq | Стандартный ответ для отсутствующего маршрута; содержимое FAQ отсутствует |
| GET /faq/api | Стандартный ответ для отсутствующего маршрута; содержимое API FAQ отсутствует |

Результат не зависит от авторизации и выбранной локали. Перенаправление на замену
не требуется.

## Поведение навигации

Навигация SPA и legacy не должна показывать FAQ, API FAQ или пустое меню справки.
Все несвязанные записи навигации сохраняют существующие подписи, адреса и
видимость.

## Совместимость API

Удаление страницы документации FAQ не удаляет фактический API endpoint только по
причине его упоминания на этой странице. Endpoints, у которых найдены потребители
внутри репозитория вне удаляемой FAQ-поверхности, остаются доступными. Endpoint и
его реализацию можно удалить, если аудит по репозиторию не находит таких
потребителей. Внешние клиенты без следов в репозитории в этот аудит не входят.
