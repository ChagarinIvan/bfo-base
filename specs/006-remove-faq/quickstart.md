# Быстрый старт: проверка удаления FAQ

## Предварительные условия

- Зависимости проекта установлены.
- Тестовая база данных приложения доступна для PHPUnit.
- Node.js 22+ и npm 10+ доступны для проверок SPA.

## Автоматические проверки

Выполнить из корня репозитория:

    composer test
    composer cs
    composer stan
    composer rector -- --dry-run
    npm run ci

Ожидаемый результат: все проверки проходят; ни один тест не сообщает о маршруте
или записи навигации FAQ.

## Дымовые проверки маршрутов

Запустить приложение обычным локальным способом и выполнить запросы:

    GET /faq
    GET /faq/api

Ожидаемый результат: оба запроса возвращают стандартный ответ приложения для
отсутствующего маршрута и не содержат удалённого содержимого FAQ.

## Аудит репозитория

Выполнить поиск в активном коде по следующим строкам:

    ShowFaqAction
    ShowApiFaqAction
    isFaqRoute
    isFaqApiRoute
    /faq
    app.faq.
    app.api.
    spa.nav.faq
    spa.nav.api

Ожидаемый результат: в активном коде не остаётся ссылок, кроме намеренно
сохранённых реализаций API, выявленных аудитом использования, и упоминаний в
спецификации/истории фичи.
