# Контракт таблицы и экспорта кубка

`GET /api/v1/cups/{cupId}/tables/{groupId}` возвращает `personName` и числовой `personYear` из карточки. Параметр `name` ищет по имени из карточки.

`GET /api/v1/cups/{cupId}/export` использует те же значения в HTML и XLSX для полного экспорта и экспорта группы. Неизвестный год представлен числом 0. Форматы ответов и права доступа сохраняются.

`GET /api/v1/cup-events/{cupEventId}/points` заполняет `personName` и `personYear` из связанной карточки. При отсутствии карточки используются значения протокола. Неизвестный год содержит 0. Параметр `name` фильтрует отображаемое имя. Очки и время сохраняют значения результата этапа.
