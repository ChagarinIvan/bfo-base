# Данные спортсменов в таблицах кубков

**Дата**: 2026-11-26

## Пользовательская история

Как пользователь таблицы кубка, я хочу видеть фамилию, имя и год рождения из карточки спортсмена, чтобы узнавать участника, даже если в протоколах этапов записаны другие данные.

## Сценарии приёмки

1. Если имя, фамилия и год рождения различаются в карточке и протоколе, таблица и выгрузки HTML и XLSX показывают данные карточки. Поиск в таблице находит спортсмена по фамилии или имени из карточки.
2. Если в карточке нет даты рождения, поле `personYear` содержит 0, как принято для неизвестного года.
3. Если карточку исправили после построения таблицы, после штатного сброса кэша таблица и выгрузки показывают обновлённые данные.
4. На странице обновлений видна одна запись об исправлении со ссылкой на список кубков.
5. В таблице отдельного этапа спортсмен с привязанной карточкой виден под фамилией и именем из карточки. Если в протоколе нет года и времени, таблица всё равно показывает год из карточки. Поиск находит спортсмена по данным карточки.

## Требования

- **FR-001**. Для всех типов кубков использовать фамилию, имя и год рождения из связанной карточки. Сохранить числовое представление неизвестного года.
- **FR-002**. Применять данные карточки в таблице, поиске по имени и выгрузках HTML и XLSX. Сохранить действующие правила расчёта очков, мест, выбора клуба и ссылок на этапы.
- **FR-003**. После выпуска перестроить таблицы, закэшированные со старым источником данных. После штатного редактирования карточки сбрасывать кэш кубков после фиксации транзакции.
- **FR-004**. Добавить в историю обновлений краткое описание исправления на белорусском языке без персональных данных.
- **FR-005**. Для таблицы отдельного этапа применять тот же источник имени и года для спортсменов со связанной карточкой. Для строки без карточки сохранить данные протокола. Время и очки по-прежнему определяются результатом этапа.

## Критерий успеха

Запросы таблицы и выгрузок проходят регрессионную проверку с заведомо разными значениями в карточке и протоколе. Проверка повторного чтения подтверждает обновление закэшированной таблицы после правки карточки.

Регрессионный тест этапа подтверждает, что поиск находит спортсмена по имени из карточки и возвращает год рождения из неё даже для строки без времени и года в протоколе.
