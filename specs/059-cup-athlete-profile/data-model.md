# Строка таблицы кубка

| Поле | Источник |
|---|---|
| `personId` | Связанный спортсмен |
| `personName` | Фамилия и имя из карточки через пробел, с обрезкой внешних пробелов |
| `personYear` | Год даты рождения из карточки или 0 |
| `clubName` | Клуб из протокола |
| `place`, `stages`, `totalPoints`, `averagePoints` | Действующий расчёт результатов |

Строка без связанного спортсмена в итоговую таблицу не попадает.
