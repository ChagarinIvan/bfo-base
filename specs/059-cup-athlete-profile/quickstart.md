# Проверка

1. Подготовить спортсмена с разными именем, фамилией и годом рождения в карточке и протоколе этапа.
2. Открыть таблицу, найти спортсмена по имени из карточки и сверить данные в HTML и XLSX.
3. Исправить карточку после первого чтения таблицы. После обработки события снова открыть таблицу и сверить поля.
4. Запустить `composer test` на тестовой БД, `composer cs`, `composer stan`, `composer rector -- --dry-run` и `npm run ci` на Node.js 22. Проверить запуск через `php artisan serve` и `git diff --check`.
5. На странице `/app/updates` проверить запись о таблицах кубков, её дату и ссылку на `/app/cups`.
