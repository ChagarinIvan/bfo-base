# Quickstart: параметры дистанции на странице этапа

1. Подготовить этап с двумя группами и разными дистанциями, например 2600 м / 26 КП и 3100 м / 18 КП.
2. Без входа открыть `/app/events/{eventId}`. Проверить рядом с выбранной группой `2,6 км` и `26 КП`.
3. Выбрать вторую группу. Проверить `3,1 км` и `18 КП`, отсутствие прежних значений и отсутствие нового запроса за параметрами.
4. Открыть прямую ссылку `/app/events/{eventId}?distanceId={distanceId}` для второй группы. Проверить те же параметры.
5. Проверить этап без дистанций и дистанцию с нулевыми значениями. Первый сохраняет сообщение «Няма дыстанцый.», вторая показывает `0 км` и `0 КП`.
6. Запустить узкий тест страницы: `npm run test -- resources/spa/pages/events/EventViewPage.test.ts`.

Поведение и единицы измерения определены в [контракте](contracts/event-distance-details.md).
