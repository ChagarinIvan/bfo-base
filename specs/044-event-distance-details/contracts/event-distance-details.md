# Контракт параметров группы на странице этапа

Публичная страница `/app/events/{eventId}` получает существующий список через `GET /api/v1/distances?eventId={eventId}`. Формат ответа не меняется: каждая дистанция уже содержит `id`, `eventId`, `groupName`, `length` в метрах и `points` как число КП.

В разделе «Вынікі» рядом с выбором «Дыстанцыя» показываются параметры только выбранной дистанции: `Даўжыня: 2,6 км · 26 КП` для `length=2600`, `points=26`. Дробная часть километров использует запятую и до трёх знаков; нули выводятся явно. Названия единиц берутся из действующих белорусских подписей.

Смена группы меняет параметры сразу по выбранному ID. Прямая ссылка с `distanceId` показывает параметры выбранной по ссылке дистанции. Когда дистанции нет или раздел результатов ещё недоступен из-за обработки протокола, строка параметров отсутствует. Гость видит её без входа. Новых запросов, записей и правил доступа нет.
