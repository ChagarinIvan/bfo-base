# Feature Specification: Параметры дистанции выбранной группы на странице этапа

**Feature Branch**: `master`

**Created**: 2026-10-11

**Status**: Implemented

**Input**: Пункт 3 `plan.txt`: на странице этапа при просмотре группы не показаны параметры дистанции и количество КП этой группы.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Видеть параметры выбранной группы (Priority: P1)

Посетитель открывает страницу этапа и выбирает группу в разделе результатов. Рядом с выбором группы он видит длину её дистанции в километрах и количество контрольных пунктов. При выборе другой группы значения меняются вместе с выбранной дистанцией.

**Why this priority**: Без этих сведений таблицу результатов трудно оценить: длина дистанции и число КП относятся к конкретной группе.

**Independent Test**: Открыть этап с двумя группами, у которых разные длина и число КП. Сверить показанные значения для группы по умолчанию, затем переключить группу и сверить их снова без обновления страницы.

**Acceptance Scenarios**:

1. **Given** этап с группой, чья дистанция имеет длину 2600 м и 26 КП, **When** посетитель открывает результаты этой группы, **Then** рядом с выбором группы он видит `2,6 км` и `26 КП`.
2. **Given** у этапа есть две группы с разными параметрами, **When** посетитель выбирает вторую группу, **Then** длина и количество КП соответствуют второй группе; значения первой больше не показаны.
3. **Given** ссылка на этап указывает на конкретную дистанцию, **When** посетитель открывает ссылку, **Then** показаны параметры выбранной по ссылке группы.
4. **Given** посетитель не вошёл в систему, **When** он открывает результаты этапа, **Then** параметры выбранной группы доступны ему так же, как таблица результатов.

### Edge Cases

- Если у этапа нет дистанций, остаётся существующее пустое состояние; параметры группы не выводятся.
- Если длина или число КП равны нулю, выводится `0 км` или `0 КП`, а не пустое значение.
- Если у выбранной группы нет строк результатов, её параметры всё равно видны.
- Пока результаты этапа ещё обрабатываются и выбор группы недоступен, параметры группы не показываются.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Страница этапа MUST показывать длину дистанции и количество КП для текущей выбранной группы в разделе результатов.
- **FR-002**: Длина MUST отображаться в километрах с десятичной запятой при дробном значении; исходное значение в метрах MUST сохранять точность до одного метра.
- **FR-003**: Количество КП MUST отображаться целым числом с подписью `КП`.
- **FR-004**: При смене группы, открытии ссылки с выбранной дистанцией и обновлении доступных дистанций показанные параметры MUST соответствовать текущему выбору.
- **FR-005**: Параметры MUST быть доступны без авторизации и MUST не показываться, когда нет выбранной дистанции.
- **FR-006**: Фича MUST не менять результаты, расчёты дистанций или сохранённые данные.

### Key Entities

- **Этап**: событие, на странице которого выбирают группу и смотрят результаты.
- **Дистанция группы**: выбранная группа с длиной в метрах и числом КП.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Для каждой проверенной группы длина и количество КП на странице совпадают с её сохранёнными параметрами.
- **SC-002**: При переключении между двумя группами оба значения меняются без перезагрузки страницы и не остаются от предыдущей группы.
- **SC-003**: Посетитель видит параметры одновременно с выбранной группой, без дополнительного действия.
- **SC-004**: Этап без дистанций не показывает вымышленные параметры и сохраняет понятное пустое состояние.

## Assumptions

- Под «параметрами» в пункте 3 понимается длина дистанции; количество КП указано отдельно.
- Длина группы хранится в метрах, а для посетителя показывается в километрах.
- Параметры дистанций уже внесены в этап; эта фича отображает сохранённые значения.
