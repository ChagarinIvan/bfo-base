# Data model: параметры дистанции на странице этапа

Новых таблиц, полей и миграций нет. Фича только читает существующие данные.

## Дистанция группы

| Поле | Смысл |
| --- | --- |
| `id` | Идентификатор выбранной дистанции |
| `eventId` | Этап, которому принадлежит дистанция |
| `groupName` | Название группы в выборе дистанций |
| `length` | Длина в метрах, целое число |
| `points` | Количество контрольных пунктов, целое число |

`distanceId` страницы выбирает ровно одну дистанцию из списка этапа. Представление длины равно `length / 1000` километра с точностью до одного метра. При отсутствии выбранной дистанции параметры не показываются. Нулевые значения остаются видимыми.
