# Quickstart

1. Create an event with a protocol and observe the queued/parsing notice.
2. Confirm the detail page refreshes both status and visible result lines every five seconds through identifying and rebuilding ranks.
3. Retry one rank-job and confirm it is counted once; retry a ready parse-job and confirm it does not return to parsing.
4. Confirm ready results stop polling; a parser error shows the authenticated error message.
5. Confirm public list/detail reject no-protocol, in-progress and failed events.
