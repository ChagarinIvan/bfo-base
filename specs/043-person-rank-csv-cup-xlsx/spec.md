# Feature Specification: Экспорт разрядов и таблиц кубка

**Feature Branch**: `master`
**Created**: 2026-10-09
**Status**: Implemented
**Input**: Пункт 2 `plan.txt` и уточнение пользователя: CSV разрядов по фильтру списка персон, белорусский формат таблицы кубка, XLSX вместо CSV, отдельный лист для каждой группы при полном экспорте.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Скачать разряды по фильтру (Priority: P1)

Авторизованный пользователь фильтрует список персон, в том числе по разряду, и скачивает CSV со всеми подходящими активными персонами. Файл содержит `lastname;firstname;birthday;rank`; `birthday` содержит только четырёхзначный год.

**Why this priority**: Возвращает необходимый экспорт разрядов без отдельной страницы.

**Independent Test**: Создать персон с разными разрядами и годами, применить несколько фильтров, скачать CSV и сравнить все строки с полным отфильтрованным списком, включая строки вне первой страницы.

**Acceptance Scenarios**:

1. **Given** авторизованный пользователь и выбранный разряд, **When** он нажимает «Экспарт CSV», **Then** получает файл только с персонами выбранного разряда.
2. **Given** одновременно выбраны имя, клуб, разряд и год, **When** пользователь скачивает файл, **Then** файл содержит все совпадения независимо от текущей страницы списка.
3. **Given** гость, **When** он смотрит список, **Then** кнопки экспорта нет; прямой запрос файла отклоняется.

---

### User Story 2 - Скачать таблицу кубка в XLSX (Priority: P1)

Авторизованный пользователь выбирает XLSX в меню экспорта кубка. Полный файл содержит отдельный лист на каждую группу. Экспорт одной группы содержит один лист и исключает участников с нулевой суммой очков. Зачётные ячейки этапов выделены жирным.

**Why this priority**: XLSX сохраняет выделение зачётных результатов, которое невозможно передать CSV.

**Independent Test**: Скачать полный файл кубка с несколькими группами, открыть его и сверить названия листов, столбцы, результаты, выделение зачётных очков и отдельный экспорт группы.

**Acceptance Scenarios**:

1. **Given** кубок с двумя группами, **When** скачан полный XLSX, **Then** файл содержит два листа в порядке групп.
2. **Given** группа с результатами, **When** скачан её XLSX, **Then** в единственном листе нет строк с нулевой суммой очков.
3. **Given** зачётные и незачётные результаты этапов, **When** файл открыт в Excel, **Then** только зачётные ячейки этапов выделены жирным.

---

### User Story 3 - Читать экспорт кубка на белорусском языке (Priority: P2)

Пользователь скачивает XLSX или HTML кубка с одинаковым порядком и смыслом столбцов: `№`, `Прозвішча, Імя`, `Год`, даты этапов, `Ачкі`, `Сярэдняе`, `Месца`.

**Why this priority**: Экспорт должен соответствовать прежнему привычному виду таблицы и языку сайта.

**Independent Test**: Сверить заголовки, даты и значения обоих файлов с полной таблицей кубка для нескольких этапов.

**Acceptance Scenarios**:

1. **Given** кубок с несколькими этапами, **When** скачан XLSX или HTML, **Then** даты представлены как `дд.мм`, а итоговые колонки следуют после этапов.
2. **Given** отфильтрованная группа, **When** скачан HTML, **Then** строки с нулевой суммой очков исключены так же, как в XLSX.

### Edge Cases

- Нет подходящих персон: CSV содержит только заголовок.
- Дата рождения не указана: поле `birthday` пустое.
- Пустая группа: лист или HTML-таблица содержит заголовки без вымышленных строк.
- Несколько групп с одинаковыми или длинными именами: листы имеют разные допустимые для Excel имена.
- Имена с кириллицей, кавычками, разделителями и переводами строки читаются как текст.
- Неверные фильтры, формат, группа или неизвестный кубок возвращают ошибку без файла.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Кнопка CSV разрядов и маршрут скачивания MUST быть доступны только авторизованным пользователям.
- **FR-002**: CSV разрядов MUST применять те же фильтры `name`, `clubId`, `rankId`, `birthYear` и те же правила активных персон, что список.
- **FR-003**: Экспорт MUST включать все совпадения в стабильном порядке фамилия, имя, ID, независимо от пагинации списка.
- **FR-004**: CSV MUST иметь заголовок `lastname;firstname;birthday;rank`, UTF-8 с BOM, разделитель `;` и четыре цифры года рождения или пустое значение.
- **FR-005**: Значение `rank` MUST быть привычной текстовой меткой текущего разряда, включая `б/р`.
- **FR-006**: Экспорт кубка MUST предлагать XLSX и HTML. CSV кубка MUST исчезнуть из меню и перестать приниматься маршрутом; запрос без `format` MUST возвращать XLSX.
- **FR-007**: Полный XLSX MUST содержать по одному листу на группу в порядке кубка, а экспорт группы MUST содержать один лист.
- **FR-008**: XLSX MUST выделять жирным ячейки этапов, которые учтены в сумме; незачётные этапы MUST оставаться обычными.
- **FR-009**: XLSX и HTML MUST использовать колонки `№`, `Прозвішча, Імя`, `Год`, даты этапов в виде `дд.мм`, `Ачкі`, `Сярэдняе`, `Месца` в указанном порядке.
- **FR-010**: Экспорт выбранной группы в обоих форматах MUST исключать строки, чья итоговая сумма очков равна нулю; полный экспорт сохраняет все строки.
- **FR-011**: Оба формата MUST брать очки, среднее, место и признак зачёта из общей рассчитанной таблицы кубка без повторного расчёта.
- **FR-012**: Ошибка валидации, отсутствие доступа и неизвестный кубок MUST возвращать действующие ответы API без attachment.

### Key Entities *(include if feature involves data)*

- **Строка экспорта разрядов**: фамилия, имя, год рождения, метка текущего разряда.
- **Секция таблицы кубка**: группа, этапы и строки участников с итоговыми очками, средним, местом и признаком зачётных этапов.
- **Книга кубка**: листы секций групп в порядке кубка.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 100% строк CSV разрядов совпадают с активными персонами, подходящими под выбранные фильтры, включая последующие страницы списка.
- **SC-002**: CSV открывается с читаемой кириллицей, а все непустые значения `birthday` имеют ровно четыре цифры.
- **SC-003**: Полный XLSX имеет ровно один лист на группу, а групповой XLSX ровно один лист.
- **SC-004**: Все зачётные ячейки XLSX выделены жирным; ни одна незачётная не выделена.
- **SC-005**: XLSX и HTML содержат заданные белорусские колонки и одинаковые значения строк; групповой экспорт не содержит нулевые итоги.

## Assumptions

- Эта спецификация заменяет контракт CSV кубка из `specs/042-cup-html-export`; его артефакты сохраняют историю ранее реализованной функции.
- Текущий разряд берётся из сохранённого поля персоны, как в фильтре списка.
- Отсутствующая дата рождения даёт пустой год, а не `0000`.
- `№` означает порядковый номер видимой строки; `Месца` сохраняет рассчитанное место.
- Фильтр имени короче трёх символов не отправляется из SPA, как в текущем списке.
- HTML остаётся доступным форматом; изменяется его табличный вид и групповой отбор нулевых строк.
