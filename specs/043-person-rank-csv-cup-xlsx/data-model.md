# Data model: экспорт разрядов и таблиц кубка

Новых таблиц и миграций нет. Все операции только читают данные.

## Строка CSV персон

`lastname` и `firstname` берутся из активной персоны; `birthday` содержит четыре цифры года либо пустое значение; `rank` содержит `Rank::label()` сохранённого текущего разряда. Фильтры `name`, `clubId`, `rankId`, `birthYear` совпадают с листингом.

## Секция экспорта кубка

Существующий `ExportCupTableSectionDto` хранит имя группы, даты этапов и строки таблицы. Строка содержит `personName`, `personYear`, `place`, `totalPoints`, `averagePoints` и этапы с `points` и `counted`. `CupTableBuilder` исключает нулевые итоги по необязательному флагу, сохраняя рассчитанное `place`. `№` задаётся порядком видимой строки. Для полного экспорта сохраняются все секции и строки; при `groupId` остаётся одна секция без нулевых итогов.

## XLSX

Каждая секция становится листом. Имя листа должно быть уникальным, не длиннее 31 символа и без символов `[]:*?/\\`. Ячейки имён записываются как текст. Даты этапов в заголовке представлены текстом `дд.мм`. Жирное начертание применяется только к зачётным ячейкам этапов.
