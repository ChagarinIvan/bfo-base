# Quickstart: проверка экспорта

1. Запустить API и SPA, войти в систему.
2. На странице персон выбрать разряд и другие фильтры, нажать «Экспарт» рядом с кнопкой добавления персоны. Проверить четыре колонки, год рождения и строки за пределами первой страницы. Повторить с пустым результатом и без входа.
3. Открыть кубок с несколькими группами и скачать XLSX. Проверить отдельный лист на группу, белорусские колонки, даты `дд.мм` и жирные зачётные очки.
4. Открыть таблицу группы и скачать XLSX и HTML. Проверить, что нулевых итогов нет и обе таблицы содержат одинаковые строки. Проверить ошибку `format=csv`.
5. Запустить узкие PHPUnit и Vitest тесты из [tasks.md](tasks.md), затем финальные `composer test`, `composer stan`, `composer cs`, Rector dry-run и `npm run ci`.
