# Audit contract

Публичные маршруты и JSON-поля не изменяются.

## Внутренний контракт фабрики

ProtocolLinesFactory.create(Event event, list<ProtocolLineInput> inputs, int userId)
возвращает list<ProtocolLine>. userId обязателен. Event.parse передаёт impression.by.
Каждая возвращённая строка уже содержит оба impressions. Clock читается в фабрике.

## Миграция

up проверяет источники исторического аудита до DDL, добавляет четыре поля,
переносит данные и запрещает null. Ошибка содержит id повреждённой строки.
down удаляет только эти четыре поля. Выполнять при остановленных импортных
воркерах и запретить конкурентные записи на время обновления схемы.

## Переходы и события

Сигнатуры assignPerson/setPerson/activateRank сохраняются; updated равен их
Impression. Публикация существующих событий и транзакции остаются прежними.
Миграция не создаёт событий. Отдельное событие технического создания не вводится.

## Объединение событий

Производные строки получают created = updated = newEvent.created после финального
replicate и до save. Аудит исходных строк не переносится в новую операцию.
Impression нового Event создаётся его фабрикой через Clock с автором объединения.
