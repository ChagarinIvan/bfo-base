# Контракт активации

Новые маршруты и поля не вводятся. Используются действующие V1 API истории и активации из `specs/018-persons-spa-ranks/contracts/`.

- Новая строка I разряда отдаёт дату активации `null` и не меняет текущий разряд.
- Действующий запрос активации принимает дату и запускает пересчёт истории и текущего разряда.
- Изменение или снятие даты использует действующий update-сценарий.
- Строки КМС и МС сохраняют автоматическую активацию повторного подтверждённого выполнения.
