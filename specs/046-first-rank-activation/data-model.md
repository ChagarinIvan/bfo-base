# Модель данных: активация I разряда

| Запись | Поле | Правило |
|---|---|---|
| `protocol_lines` | `complete_rank` | `I` обозначает выполнение I разряда. |
| `protocol_lines` | `activate_rank` | `NULL` у нового I разряда до подтверждения; после подтверждения содержит дату. У старого активированного I разряда дата уже записана и не меняется. |
| `person_rank_histories` | `rank`, `activated_on`, `started_on`, `finished_on` | Производная история; выполнение без даты активации остаётся записью без действующего периода. |
| `person` | `current_rank` и даты | Производное текущее состояние, пересчитывается после ручной активации. |

Переход `новое выполнение → ожидание → ручная активация → действующий период` использует существующий API. У уже активированной строки перехода нет. Схема БД не меняется.
