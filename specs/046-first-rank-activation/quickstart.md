# Проверка: активация I разряда

1. Запустить узкие тесты `RankTest`, `RankCalculatorTest` и `FirstRankActivationTest`.
2. Проверить новый протокол с I разрядом: дата активации пуста, история содержит выполнение, текущий I разряд не появляется.
3. Активировать строку через существующий API и проверить начало и конец срока в истории и текущем разряде.
4. Повторить для спортсмена с прежним I разрядом: новая строка ожидает подтверждения, старый период остаётся прежним.
5. Пересчитать спортсмена со старой активированной строкой I разряда и проверить, что дата в строке, история и текущий период не изменились. Миграция данных не требуется.
6. В конце фичи выполнить `composer test`, `composer stan`, `composer cs`, `composer rector -- --dry-run` и проверить запуск приложения.
