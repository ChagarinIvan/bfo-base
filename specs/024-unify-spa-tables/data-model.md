# Модель данных: единые SPA-таблицы

## Конфигурация таблицы

| Атрибут | Смысл |
|---------|-------|
| `tableId` | Стабильный уникальный идентификатор листинга. |
| `accessVariant` | `guest` или `authenticated`; часть ключа хранения. |
| `visibleColumnKeys` | Непустой упорядоченный список разрешённых ключей колонок. |

Конфигурация живёт только в browser storage. При чтении неизвестные или недоступные ключи
отбрасываются; если после этого список пустой, используется default layout.

## Описание столбца

| Атрибут | Смысл |
|---------|-------|
| `key` | Стабильный ключ без привязки к локализованной строке. |
| `label` | Пользовательская подпись. |
| `defaultVisible` | Входит ли колонка в начальное представление. |
| `available` | Доступна ли колонка в текущем access variant. |

## Ручной пересчёт

`personId` маршрута идентифицирует единственного спортсмена; `userId` берётся из auth context
и фиксируется как author impression существующего пересчёта. Новые persistent entities не нужны.
