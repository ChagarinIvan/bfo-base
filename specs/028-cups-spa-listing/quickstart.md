# Quickstart: SPA-листинг кубков

1. Open `/app/cups` anonymously and verify the current year is selected.
2. Verify only visible cups are shown and the visibility selector is absent.
3. Search by a partial cup name and change the year; verify filters reset pagination.
4. Authenticate, reload `/app/cups`, and verify the visibility selector and authenticated
   columns/actions appear.
5. Select visible, invisible, and all modes and verify each result set.
6. Follow a cup name and group/table link and verify the existing cup routes open.
7. Verify `/cups` is no longer registered while `/cups/{id}/show` remains registered.
