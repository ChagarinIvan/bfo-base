# Контракт Albatros-Timing parser

`AlbatrosTimingParser::parse()` возвращает коллекцию строк протокола. Для каждой строки
из `20260404.htm` контракт требует:

- parser factory выбирает `AlbatrosTimingParser`;
- `group` равен названию ближайшего предшествующего заголовка `h2`;
- обычная строка содержит параметры дистанции, время и место;
- строка с `DSQ` или `DSQ6` содержит `time: null` и `place: null`, но сохраняет
  группу, имя и стартовый номер;
- отсутствие уровня соревнований не удаляет строки группы;
- прежние поля и их типы не меняются.

Изменение не создаёт HTTP-, CLI- или database-контрактов.
