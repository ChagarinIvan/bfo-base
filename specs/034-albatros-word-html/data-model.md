# Модель данных: Albatros-Timing Word HTML

Постоянная модель данных не меняется. Parser возвращает существующую структуру строки
протокола:

| Поле | Значение в этой фиче |
|------|----------------------|
| `group` | Название ближайшего заголовка блока: М1–М5 или Ж1–Ж5. |
| `distance.length`, `distance.points` | Параметры дистанции из начала блока группы. |
| `lastname`, `firstname`, `club` | Персональные данные участника. |
| `year`, `rank`, `runner_number` | Стартовые данные из строки результата. |
| `time`, `place` | Обычный результат или `null` у `DSQ`/`DSQ6`. |
| `complete_rank`, `points`, `vk` | Существующие необязательные значения без изменения семантики. |

Блок группы относится к каждой вложенной строке результата. Служебные строки и блоки
уровня соревнований не создают результатов и не меняют группу следующего блока.
