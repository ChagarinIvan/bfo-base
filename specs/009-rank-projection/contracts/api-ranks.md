# Контракт: справочник разрядов

## GET /api/v1/ranks

Публичный read-only endpoint возвращает прямой JSON-массив всех cases `Rank` в стабильном
доменном порядке: от сильнейшего разряда к отсутствию разряда.

```json
[
  {"id": 9, "label": "МСМК"},
  {"id": 8, "label": "МС"},
  {"id": 7, "label": "КМС"},
  {"id": 6, "label": "I"},
  {"id": 0, "label": "б/р"}
]
```

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer | Backed value enum `Rank`, стабильный идентификатор для API, persistence и параметров фильтра. |
| `label` | string | Строковое представление enum для отображения пользователю. |

Endpoint не требует авторизации и не имеет параметров. Клиент кэширует успешный ответ в
памяти и `localStorage` на один час, с проверкой схемы сохранённого кэша; cache miss,
истечение срока или некорректные данные запускают повторный запрос.
