# Контракт OBelarus.net parser

`OBelarusNetParser::parse()` возвращает коллекцию строк протокола. Для каждой строки
из `20260911.htm` контракт требует:

- `group` равен названию ближайшего предшествующего заголовка группы;
- обычная строка содержит время и место;
- строка без результата содержит `time: null` и `place: null`, но сохраняет `group`,
  имя и стартовый номер;
- прежние поля и их типы не меняются.

Изменение не создаёт HTTP-, CLI- или database-контрактов.
